### University Clone Frontend Project

This project is a frontend-only clone of a university website. It replicates the structure and design of a typical academic institution's website,
including key sections such as the homepage, about page, courses, faculty, and contact information.
The primary goal of this project is to demonstrate proficiency in HTML, CSS, and responsive design principles.

### Features:-

### Homepage: ###

- Attractive banner with the university's slogan or welcome message.

- Navigation bar with links to all major sections.

### Courses Page: ###

- List of courses offered by the university.

- Filters for categories like undergraduate, postgraduate, and certifications.

### Admission Page: ###

- List of courses offered by the university.

- Detailed information for education loan and finance

### Faculty Page: ###

- Profiles of key facultys .

- Designation and specialization details.

### Contact Page: ###

- Contact form for inquiries.

- Google Maps integration for the university location.

### Responsive Design: ###

- Fully responsive layout optimized for desktop, tablet, and mobile devices.


### Technologies Used ###

- HTML5: For the website’s structure.

- CSS3: For styling and layout.

- Bootstrap: For responsive design and pre-built components.


### How to Run the Project ###

1) Clone or download the repository.

2) Open the index.html file in any web browser.

3) Navigate through the website using the menu links.
